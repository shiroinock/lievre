# 参考ピンの見直し：ほかの配色、退廃的な空気感、そのほかの要素

2026-10-24 に、ボードの81件（[一覧ビューア](pinterest/index.html)・[カタログ](pinterest/catalog.json)）をもう一度見て、今の lievre にまだ取り入れていない要素を選びました。きっかけは「今の計はきれいすぎる。もう少し退廃的な空気感がほしい」「他のカラースキームも」という声です。

A〜D の候補は、今の方針である「平らな面と1pxの線」「影を使わない」「文字と背景は4.5:1以上」を守ります。崩すのは**面の上の質感**と**色の温度**だけで、文字・操作の輪郭・状態の色には手を入れません。E には、方針と衝突するものを外さずに残し、取り入れるならどういう形がありうるかを添えました。

- 優先度は **高**（すぐ試す価値がある）、**中**（試作の結果を見て決める）、**低**（見送りが妥当）の3段階です。
- 「試作」と書いた候補は、この PR で Storybook の「Foundations / 試作 配色と擦れ」と demo アプリで見比べられます。
- 分類と読み取りはアシスタントの解釈です。どのピンをユーザーが特に気に入っているかは確認していません。

## この PR で試作したもの

- **テーマ2つ（採用しないことに決まり、外しました）**：`sepia` と `rust` を試作しましたが、採用しないことに決まりました。テーマは Paper と Ink のままです。物質感は、テーマではなく質感（`wear`）の側で出します。
- **質感（`wear`）**：`LievreProvider` に `wear="off | baked | live"` と `wearSeed` を足し、`src/styles/lievre-wear.css` に B1〜B4 と文字のカスレをまとめました。Storybook の上部の「質感」で、どの部品にも質感を付けて見られます。ダイアログなどのポータルにも引き継がれます。仕組みと計測の結果は [wear-prototype.md](wear-prototype.md) にあります。
- **検査**：`src/test/contrast.test.tsx` に、粒が最も濃い点での文字のコントラストの検査を加えました。
