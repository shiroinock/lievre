# 参考ピンの見直し：ほかの配色と退廃的な空気感

2026-10-24 に、ボードの81件（[一覧ビューア](pinterest/index.html)・[カタログ](pinterest/catalog.json)）をもう一度見て、今の KEI にまだ取り入れていない要素を選びました。きっかけは「今の計はきれいすぎる。もう少し退廃的な空気感がほしい」「他のカラースキームも」という声です。

どの候補も、今の方針である「平らな面と1pxの線」「影を使わない」「文字と背景は4.5:1以上」は守ります。崩すのは**面の上の質感**と**色の温度**だけで、文字・操作の輪郭・状態の色には手を入れません。

- 優先度は **高**（すぐ試す価値がある）、**中**（試作の結果を見て決める）、**低**（見送りが妥当）の3段階です。
- 「試作」と書いた候補は、この PR で Storybook の「Foundations / 試作 配色と擦れ」と demo アプリで見比べられます。
- 分類と読み取りはアシスタントの解釈です。どのピンをユーザーが特に気に入っているかは確認していません。

## この PR で試作したもの

- **テーマ2つ**：`sepia` と `rust` を `src/styles/kei.css` のトークン層に追加し、`tokens/tokens.json` にも書き出しました。Storybook の上部の「配色」と、demo アプリのサイドバーで切り替えられます。
- **擦れ（`wear="worn"`）**：`KeiProvider` に `wear` を足し、`src/styles/kei-wear.css` に B1〜B4 をまとめました。Storybook の上部の「質感」で、どの部品も擦れた状態で見られます。ダイアログなどのポータルにも引き継がれます。
- **検査**：`src/test/contrast.test.tsx` を4テーマに広げ、粒が最も濃い点での文字のコントラストも検査に加えました。

## 採用するときに決めること

1. テーマを4つにするか、Sepia か Rust のどちらかに絞るか。
2. 刷りのずれ（B2）を入れる場合、「影を使わない」を「奥行きを示す影を使わない」に言い直すか。
3. `wear` を正式な設定にする場合、`kei-wear.css` を `kei.css` に統合するか、別の読み込みのままにするか。今は部品集（`src/library.ts`）にも含めています。
4. 次に作る部品として、C1（仕様欄）を優先するか。
