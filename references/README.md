# 参考ピンと設計への翻訳

ユーザーが共有したPinterestのUIボードにある81件を、2026-10-24時点で整理した参考資料です。

- [一覧ビューア](pinterest/index.html)：ローカルで開けるサムネイル付き一覧。検索・カテゴリ絞り込み・元ピンへのリンク。
- [ピン81件のカタログ](pinterest/catalog.json)：各URL、分類、観察メモ、設計への応用候補。
- [参考ストックと方針の記録](design-references.json)：ボードとユーザーの好み、検討過程。初期の用途表記も履歴として残しています。現在のシステムは管理画面を含む汎用用途が対象です。
- [設計意図](../DESIGN.md)：参考の特徴を共通ルールへ翻訳した内容。

ビューアは `references/pinterest/index.html` をブラウザで開いてください。GitHubのファイル画面はHTMLを表示しないため、サムネイルを並べて見る場合はローカルで開きます。

サムネイルは共有ボードの画面から切り出した参考用画像です。各ピンの全スライド・動画全編・元サイトまでは精査していません。分類・観察・応用候補はアシスタントの解釈であり、個々のピンについてのユーザーの評価とは区別しています。元の画像・作品の権利は各権利者に帰属します。生のブラウザキャプチャやセッション情報は含めていません。
