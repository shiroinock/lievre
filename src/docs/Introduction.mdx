# KEI / 計

**読む。測る。手を動かす。**

Webアプリ、読み物、登録フロー、管理画面などに使う、日本語を中心に据えた汎用デザインシステムの最初の案です。81件の参考にある「計器の精密さ」「印刷物の組版」「明確な操作部」を、毎日使えるUIに翻訳しています。共通トークン、汎用部品とレイアウト、用途別パターンの3層で構成します。

## ここで試せること

- **Foundations**：配色、文字、余白と形、設計原則、参考からの翻訳。
- **Universal components**：Text / Heading / Link / ActionLink / Container / Stack / Grid / RadioGroup。
- **Components**：部品ごとのAPI、状態、ソースコード、操作例。
- **Patterns**：検索一覧、コンテンツ詳細、入力・確認・完了フロー、作業モニター、設定画面。
- 上部ツールバーの **配色**：Paper（白と青） / Ink（深い青）。ダイアログや選択メニューにも反映します。
- 上部ツールバーの **表示密度**：標準 / 高密度。文字サイズを落とさず、操作部の高さとセルの余白を調整します。
- **Controls**：propsを変更。**Accessibility**：自動検査。**Interactions**：play付きStoryの操作と結果。
- 画面幅は **Viewport** から変更できます。

本文は標準16px。`KeiProvider typography="interface"` では14pxとなり、管理画面の表現に使えます。密度は文字サイズから独立しており、入れ子のProviderは未指定のテーマ・密度・文字設定を引き継ぎます。

## 最小の使い方

このパッケージはnpmには公開していません。付属のソースを使うか、`npm run build:lib` の後に `npm pack` でローカルパッケージを作成してください。

```tsx
import { KeiProvider, Button, TextField } from '@kei-design/react';
import '@kei-design/react/styles.css';

export function Workspace() {
  return (
    <KeiProvider theme="paper" density="comfortable">
      <TextField label="ワークスペース名" defaultValue="計測ラボ" />
      <Button variant="primary">作業を追加</Button>
    </KeiProvider>
  );
}
```

## 通知を使う

`useToast` は `ToastProvider` の子孫で使います。

```tsx
function SaveButton() {
  const toast = useToast();
  return <Button onClick={() => toast({ title: '保存しました' })}>保存</Button>;
}

<KeiProvider>
  <ToastProvider><SaveButton /></ToastProvider>
</KeiProvider>
```

色だけで状態を表さず、ラベルや記号を併用します。フォーカス表示は消さず、`prefers-reduced-motion` と強制カラーにも配慮します。自動検査はアクセシビリティ全体の保証ではないため、キーボード操作と実画面でも確認します。

## いまの範囲

React + TypeScript、CSSトークン、2テーマ、2段階の密度、入力・選択・フィードバック・計器・テーブル・ナビゲーションと画面例。バックエンドとの接続は含みません。画面例のデータはローカルのサンプルで、再読み込みでリセットされます。

カレンダー、複数選択コンボボックス、大規模テーブルの仮想化、リッチテキスト、実データのチャートは、この案でまだ実装していない拡張候補です。

## 面の共通ルール

ハイライト、内側の影、ドロップシャドウを使わないフラットな表現に統一します。通常の面もダイアログや選択メニューも、単色・1pxの境界線・余白で区別します。フォーカスはアウトラインで、ホバーと押下は面色の変化で示します。フッターだけに立体効果を加えません。
