# 試作の検査の結果

`npm run check` が出した `results.json` を `node test/summary.mjs` でまとめたもの。セルは「Chromium と WebKit が同じならその記号、違えば Chromium / WebKit」。IME は合成のイベントで再現している（README を参照）。
