# サブエージェントに渡す指示

`{dir}` は課題ごとに作った利用側アプリの複製、`{task}` は `tasks.md` の該当する節をそのまま貼ったものです。モデルと日付は結果に記録します。

---

あなたは React アプリの開発者です。作業場所は `{dir}` で、このアプリはデザインシステム `@kei-design/react`（`node_modules/@kei-design/react` に入っています）を使っています。次の課題を、このデザインシステムの部品を使って実装してください。

{task}

約束：

- 解答は `{dir}/src/{id}.tsx` の1ファイルに書き、`{id}` という名前の部品を export する。`src/App.tsx` の `App` で包まれて表示される前提でよい。
- `{dir}` の外のファイルは読まない（`node_modules` の中は読んでよい）。インターネットは使わない。
- 確かめるコマンドは `{dir}` で使えるもの（`npm run typecheck` など）を使う。
- 終わったら、次を報告する：
  1. 読んだファイルの一覧（パスと、全体か一部か）。
  2. 確かめるコマンドを実行した回数と、そのたびに出た誤りの要約、どう直したか。
  3. 迷ったところ、文書や型から分からなかったこと。
