# Lièvre

日本語の画面を基準に設計した、React のコンポーネントと CSS トークンです。読み物、登録フロー、管理画面まで同じ部品で組み立てられます。ウルトラマリンを操作の色にして、影のない面と1pxの線で階層をつくります。

構成は3層です。色・文字・余白を決める **トークン**、どの画面でも使う **部品とレイアウト**、用途ごとの組み合わせを示す **画面パターン**。

## ここで試せること

- **Foundations**：配色、文字、余白と形、設計原則、参考からの翻訳。
- **Universal components**：Text / Heading / Link / ActionLink / Container / Stack / Grid / RadioGroup。
- **Components**：部品ごとのAPI、状態、ソースコード、操作例。
- **Patterns**：検索一覧、コンテンツ詳細、入力・確認・完了フロー、作業モニター、設定画面。
- 上部ツールバーの **配色**：Paper（明るい面） / Ink（深い紺の面）。ダイアログや選択メニューにも反映します。
- 上部ツールバーの **表示密度**：標準 / 高密度。文字サイズを落とさず、操作部の高さとセルの余白を調整します。
- **Controls**：propsを変更。**Accessibility**：自動検査。**Interactions**：play付きStoryの操作と結果。
- 画面幅は **Viewport** から変更できます。

本文は標準16px。`LievreProvider typography="interface"` では14pxとなり、管理画面の表現に使えます。密度は文字サイズから独立しており、入れ子のProviderは未指定のテーマ・密度・文字設定を引き継ぎます。

## 最小の使い方

このパッケージはnpmには公開していません。付属のソースを使うか、`npm run build:lib` の後に `npm pack` でローカルパッケージを作成してください。

```tsx
import { LievreProvider, Button, TextField } from '@lievre/react';
import '@lievre/react/styles.css';

export function Workspace() {
  return (
    <LievreProvider theme="paper" density="comfortable">
      <TextField label="ワークスペース名" defaultValue="計測ラボ" />
      <Button variant="primary">作業を追加</Button>
    </LievreProvider>
  );
}
```

## 通知を使う

`useToast` は `ToastProvider` の子孫で使います。

```tsx
function SaveButton() {
  const toast = useToast();
  return <Button onClick={() => toast({ title: '保存しました' })}>保存</Button>;
}

<LievreProvider>
  <ToastProvider>
    <SaveButton />
  </ToastProvider>
</LievreProvider>;
```

## いまの範囲

React + TypeScript、CSSトークン、2テーマ、2段階の密度、入力・選択・フィードバック・メーター・テーブル・ナビゲーションと画面例。バックエンドとの接続は含みません。画面例のデータはローカルのサンプルで、再読み込みでリセットされます。

カレンダー、複数選択コンボボックス、大規模テーブルの仮想化、リッチテキスト、実データのチャートは、この案でまだ実装していない拡張候補です。

## 面の共通ルール

影・光沢・グラデーションは使いません。通常の面もダイアログも選択メニューも、面の明るさ・1pxの線・余白で区別します。フォーカスはアウトライン、ホバーと押下は面の色の変化で示します。

## トークンの書き出し

`packages/tokens/tokens.css`（`@lievre/tokens`）が正です。値を変えたら `npm run tokens` で `tokens.json`（Design Tokens 形式）を作り直してください。テストで両者が一致しているかを確認しています。部品集の `styles.css` は、このトークンの層を読み込んで1つにまとめています。
